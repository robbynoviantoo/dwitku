# Folder untuk Logo Bank & E-Wallet

Letakkan file logo bank / e-wallet kamu di dalam folder ini (`public/banks/`).

Nama file disarankan menggunakan format:
- `bca.svg` / `bca.png`
- `mandiri.svg` / `mandiri.png`
- `bri.svg` / `bri.png`
- `bni.svg` / `bni.png`
- `bsi.svg` / `bsi.png`
- `jago.svg` / `jago.png`
- `seabank.svg` / `seabank.png`
- `gopay.svg` / `gopay.png`
- `ovo.svg` / `ovo.png`
- `dana.svg` / `dana.png`
- `shopeepay.svg` / `shopeepay.png`
- `linkaja.svg` / `linkaja.png`
- `astrapay.svg` / `astrapay.png`
- `cash.svg` / `cash.png`

Komponen `WalletLogo` otomatis memprioritaskan file gambar dari folder ini dan akan fallback ke teks logo jika file belum ada.
